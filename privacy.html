Privacy policy

Effective date: 14 October 2026.

autposting-backup is a personal backup application operated by its owner. It is not a public backup service and does not accept other users’ data.

Google data access and purpose

The existing Desktop OAuth client, rclone-r0, requests only https://www.googleapis.com/auth/drive.file. Through rclone, the application creates, lists, reads, uploads and updates files and folders created by this application or specifically made available to it under that permission. The purpose is to store and restore the owner’s encrypted restic repository, including repository configuration, encrypted packs, indexes, snapshots and locks. It does not request full Google Drive access, Gmail, Contacts or Calendar permissions.

Encryption and storage

restic encrypts backup contents and snapshot metadata locally before transfer. Google Drive stores the encrypted repository. Google and rclone can still process transport information and Drive file metadata such as object names, sizes and timestamps; encryption does not hide all metadata. The restic password and the owner’s recovery kit are kept separately from the repository.

The OAuth refresh token and client configuration are stored in a private local rclone configuration on the owner’s backup machine. They are used only to maintain the authorized connection. Plaintext source files, restored files, caches and operational logs may exist on owner-controlled machines. Access is restricted by the owner. Credentials and backup data are never submitted through this informational website.

Sharing and limited use

Google user data is used only to provide this personal backup and recovery function. It is not sold, used for advertising, shared with advertisers, used to assess creditworthiness, or used to train AI models. There is no third-party analytics in these pages. The owner controls access to backup data; Google processes data as the selected storage provider under its own terms. This application’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation and deletion

Backups remain until the owner intentionally deletes them under the backup retention policy. No automatic cloud pruning is enabled by this setup. The owner can revoke the application’s access in Google Account’s third-party connections settings and remove its local OAuth configuration. Revoking access stops further API access but does not automatically delete existing Drive files. To erase stored backups, the owner must delete the repository in Drive and, where applicable, empty the trash and remove local copies. Recovery copies must be considered separately.

Website and contact

This website contains static information only: no login, forms, cookies, trackers or backup upload function are implemented in its source. The hosting provider may process normal request information for delivery and security. For privacy questions, contact the owner using the user support email displayed on this application’s Google OAuth consent screen.
