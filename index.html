autposting-backup

A private, owner-operated workflow for encrypted backups and independent recovery.

restic → rclone → Google Drive
Encryption happens locally. Drive stores the encrypted restic repository.

What the application does

restic prepares an encrypted backup repository. rclone transfers repository objects to the owner’s Google Drive and retrieves them for integrity checks and restoration. This application uses the existing Desktop client rclone-r0 in project autposting-backup.

Limited permission

The only requested Google API scope is https://www.googleapis.com/auth/drive.file. It covers application-created files and files explicitly made available to the application under that permission. Full Drive access is not requested.

One owner, no public service

The owner completes Google sign-in and consent directly with Google. This website does not sign you in, connect a Google account, collect credentials or accept backup uploads. It contains no advertising or analytics code.

Read the privacy policy for data access, encryption, retention and revocation, and the terms of use for responsibilities and recovery limits. For support, use the owner’s email displayed on the application’s Google OAuth consent screen.
